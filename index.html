Trích danh sách backlink từ file export

Dùng 1 file như bình thường hoặc bật Multi file để gộp backlink từ nhiều file thành một cột. Công cụ tự nhận diện các cột phổ biến như Source url / Referring page URL, nhưng bạn vẫn có thể chọn cột thủ công.

Chọn 1 file và lấy linh động bất kỳ cột nào.
